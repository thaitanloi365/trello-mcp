# Trello MCP Tray Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a macOS menu bar app, Trello MCP, that lists the running trello-mcp servers with
their CPU and memory and can stop one, and make each server lighter.

**Architecture:** A plain-AppKit Swift app in `tray/`, built with `swiftc` into `dist/Trello MCP.app`.
- It finds servers with libproc (no `ps`).
- It samples only while its borderless panel shows.
- It draws the panel in claude-usage's Swiss design.

The Rust server switches to a current-thread tokio runtime if measurement shows it uses less memory.

**Tech Stack:** Swift 6.4 compiler (Swift 5 mode), AppKit, libproc and sysctl, Make, launchd; Rust
with tokio for the server change.

**Spec:** `/Users/loithai/Projects/ai-tools/trello-mcp/docs/superpowers/specs/2026-10-13-tray-design.md`

**Design references:**
- `/Users/loithai/Projects/ai-tools/claude-usage/DESIGN.md`
- `/Users/loithai/Projects/ai-tools/claude-usage/tray/Panel.swift` (commit 6481b6e), which the
  building blocks below are adapted from.

## Global Constraints

- The tray is macOS only. Linux and Windows builds of trello-mcp stay as they are.
  `make check` runs `tray-test` only when `uname` is Darwin.
- Build with plain `swiftc`: no Xcode project, no SwiftPM.
- Use AppKit only: no SwiftUI, no `NSPopover`, no `UserNotifications`.
- The tray never starts `ps` or any other child process.
- Names:
  - app `Trello MCP.app`
  - bundle id `com.trellomcp.tray`
  - executable `trello-mcp-tray`
  - LaunchAgent label `com.trellomcp.tray`
  - log `~/Library/Logs/trello-mcp-tray.log`
- Sampling:
  - only while the panel is visible;
  - first sample on open, then after 0.5 s, then every 2 s;
  - timer tolerance 0.2 s;
  - no timers while the panel is closed.
- Colors, as in DESIGN.md:
  - light: paper `#fff`, ink `#111`, muted `#5c5c5c`, hair `#d4d4d4`, track `#e6e6e6`, red-ink
    `#da291c`, amber `#a85600`;
  - dark: paper `#0d0d0d`, ink `#f2f2f2`, muted `#a3a3a3`, hair `#333`, track `#2a2a2a`, red-ink
    `#ff6a5c`, amber `#f0a43a`;
  - Swiss red fill `#da291c`;
  - font: Helvetica Neue with tabular digits;
  - square corners, no shadows inside the panel.
- Threshold Rule for a row's CPU: ink below 80%, amber from 80%, red from 95%.
- `make install` and `bin/trello-mcp` (the path clients run) stay as they are.
- Cargo output evidence: run checks through `rtk proxy` (for example `rtk proxy make lint`). The
  RTK hook hides cargo warnings otherwise.
- Commit messages: Conventional Commits, a few lines. No AI attribution lines.
- Work on branch `feat/tray`, never on `master`.

## Review Focus

1. **PID reused between a sample and a Stop click:** nothing is signalled. Task 2 tests a wrong
   start time and a wrong name.
2. **A server exits in the middle of a scan or right after a stop:** it drops out quietly, with no
   crash and no error box. Task 2 tests a scan after a stopped child.
3. **Folder or binary paths with spaces, and very long project names:** arguments parse whole;
   labels truncate in the middle. Task 2 tests a buffer and a live binary whose path has a space.
   Task 3's panel test renders a 60-character label at 360 pt.
4. **CPU above 100%** (a server using several threads) **and large memory:** `143%` and `1.2 GB`
   fit their columns. Task 2 tests the text; Task 3's panel test renders them at 360 pt.
5. **More servers than the screen holds:** the middle scrolls and the panel never grows past the
   screen. Task 3's panel test renders 40 rows with a 400 pt cap.

```swift
// Finding and measuring the running trello-mcp servers with libproc, stopping one, and the pure
// rules and text the panel shows them by. No AppKit here; main.swift's SELFTEST block checks it all.
import Foundation

/// The server binary's process name. The tray itself is trello-mcp-tray, so it never matches.
let serverName = "trello-mcp"
let userHome = FileManager.default.homeDirectoryForCurrentUser.path

/// A process's identity: the start time tells a reused pid apart.
struct ServerID: Hashable {
    let pid: pid_t
    let start: UInt64   // µs since 1970

    var started: Date { Date(timeIntervalSince1970: Double(start) / 1e6) }
}

/// One measured server.
struct Proc: Equatable {
    let id: ServerID
    let ppid: pid_t
    let parent: String      // the parent's process name, "" when unknown
    let folder: String?     // working folder: the project the client started it in
    let binary: String
    let config: String?     // the --config value
    let cpuNs: UInt64       // CPU time so far
    let mem: UInt64         // physical footprint in bytes: Activity Monitor's Memory
}

// MARK: - Arguments

/// Arguments after the binary, with --config and its value taken out.
func plainArgs(_ argv: [String]) -> [String] {
    var out: [String] = [], it = argv.dropFirst().makeIterator()
    while let a = it.next() {
        if a == "--config" { _ = it.next() } else if !a.hasPrefix("--config=") { out.append(a) }
    }
    return out
}

/// trello-mcp serves when its first argument, --config aside, is `serve` or there is none.
func isServer(_ argv: [String]) -> Bool { plainArgs(argv).first.map { $0 == "serve" } ?? true }

func configArg(_ argv: [String]) -> String? {
    for (i, a) in argv.enumerated().dropFirst() {
        if a == "--config" { return i + 1 < argv.count ? argv[i + 1] : nil }
        if a.hasPrefix("--config=") { return String(a.dropFirst("--config=".count)) }
    }
    return nil
}

/// argv from a KERN_PROCARGS2 buffer: argc (Int32), the exec path, NUL padding, then argc NUL-ended strings.
func parseProcArgs(_ b: [UInt8]) -> [String]? {
    guard b.count >= 4 else { return nil }
    let argc = Int(b.withUnsafeBytes { $0.loadUnaligned(as: Int32.self) })
    var i = 4
    while i < b.count, b[i] != 0 { i += 1 }     // exec path
    while i < b.count, b[i] == 0 { i += 1 }     // padding
    var out: [String] = []
    while out.count < argc, i < b.count {
        let s = i
        while i < b.count, b[i] != 0 { i += 1 }
        guard i < b.count else { return nil }   // cut off before its NUL
        out.append(String(decoding: b[s..<i], as: UTF8.self))
        i += 1
    }
    return out.count == argc ? out : nil
}

// MARK: - Labels and status

/// Each working folder's last component, after its parent when the name is shorter than 4
/// characters or another folder has the same name. Home is ~; an unknown folder is trello-mcp.
func projectLabels(_ folders: [String?], home: String) -> [String] {
    let name = { (f: String) in (f as NSString).lastPathComponent }
    var uses: [String: Int] = [:]
    for f in Set(folders.compactMap { $0 }) { uses[name(f), default: 0] += 1 }
    return folders.map { f in
        guard let f else { return serverName }
        if f == "/" { return "/" }
        if f == home { return "~" }
        let n = name(f)
        guard n.count < 4 || uses[n, default: 0] > 1 else { return n }
        let parent = (f as NSString).deletingLastPathComponent
        return parent == home ? "~/" + n : name(parent) + "/" + n
    }
}

func tilde(_ path: String, home: String) -> String {
    path == home ? "~" : path.hasPrefix(home + "/") ? "~" + path.dropFirst(home.count) : path
}

enum Status: Equatable { case stopping, orphaned, busy, idle }

/// Orphaned: the client that started it is gone and launchd adopted it.
func status(ppid: pid_t, cpu: Double?, stopping: Bool) -> Status {
    stopping ? .stopping : ppid == 1 ? .orphaned : (cpu ?? 0) > 0.05 ? .busy : .idle
}

enum Tone: Equatable { case ink, amber, red }

/// The Threshold Rule: ink below 80%, amber from 80%, red from 95%.
func tone(_ p: Double?) -> Tone { (p ?? 0) >= 95 ? .red : (p ?? 0) >= 80 ? .amber : .ink }

/// A server as the panel shows it.
struct Row: Equatable {
    let proc: Proc
    let label: String
    let cpu: Double?    // percent of one core over the last interval; nil before a second sample
    let status: Status
    var id: ServerID { proc.id }
    var mem: UInt64 { proc.mem }
}

/// Rows by project label, then start time: the order never moves as numbers tick.
func rows(_ procs: [Proc], cpu: [ServerID: Double], stopping: Set<ServerID>, home: String) -> [Row] {
    zip(procs, projectLabels(procs.map(\.folder), home: home)).map { p, label in
        Row(proc: p, label: label, cpu: cpu[p.id], status: status(ppid: p.ppid, cpu: cpu[p.id], stopping: stopping.contains(p.id)))
    }.sorted { ($0.label, $0.id.start, $0.id.pid) < ($1.label, $1.id.start, $1.id.pid) }
}

/// Same servers, labels and stopping state: a tick updates numbers in place instead of re-rendering.
func sameShape(_ a: [Row], _ b: [Row]) -> Bool {
    a.map(\.id) == b.map(\.id) && a.map(\.label) == b.map(\.label) && a.map { $0.status == .stopping } == b.map { $0.status == .stopping }
}

// MARK: - Text

/// Percent of one core between two (CPU ns, uptime s) samples; nil without an earlier one.
func cpuPercent(_ a: (cpu: UInt64, at: TimeInterval)?, _ b: (cpu: UInt64, at: TimeInterval)) -> Double? {
    guard let a, b.at > a.at else { return nil }
    return max(0, Double(b.cpu) - Double(a.cpu)) / 1e9 / (b.at - a.at) * 100
}

/// "0.6%", "143%" from 100, "—" before a second sample.
func cpuText(_ p: Double?) -> String { p.map { String(format: $0 >= 100 ? "%.0f%%" : "%.1f%%", $0) } ?? "—" }

/// "8.2 MB" under 10 MB, "49 MB", "1.2 GB" from 1024 MB.
func memText(_ b: UInt64) -> String {
    let mb = Double(b) / 1_048_576
    return mb >= 1024 ? String(format: "%.1f GB", mb / 1024) : String(format: mb < 10 ? "%.1f MB" : "%.0f MB", mb)
}

/// "4 MIN", "2H 14M", "1 DAY", "3 DAYS", rounded down.
func uptime(_ t: TimeInterval) -> String {
    let m = max(0, Int(t / 60)), d = m / 1440
    if d > 0 { return "\(d) DAY\(d == 1 ? "" : "S")" }
    return m >= 60 ? String(format: "%dH %02dM", m / 60, m % 60) : "\(m) MIN"
}

/// "IDLE · PID 3959 · UP 3 DAYS"
func statusLine(_ r: Row, now: Date) -> String {
    let word = switch r.status {
    case .stopping: "STOPPING…"
    case .orphaned: "ORPHANED"
    case .busy: "BUSY"
    case .idle: "IDLE"
    }
    return "\(word) · PID \(r.id.pid) · UP \(uptime(now.timeIntervalSince(r.id.started)))"
}

/// VoiceOver text of a row.
func rowSummary(_ r: Row, now: Date) -> String {
    "\(r.label), CPU \(cpuText(r.cpu)), memory \(memText(r.mem)), \(statusLine(r, now: now).lowercased())"
}

/// Summed CPU (nil until a server has a second sample) and memory, and the note under them.
func totals(_ rows: [Row], now: Date) -> (cpu: Double?, mem: UInt64, note: String) {
    let cpus = rows.compactMap(\.cpu)
    var parts: [String] = []
    for (s, word) in [(Status.idle, "idle"), (.busy, "busy"), (.orphaned, "orphaned"), (.stopping, "stopping")] {
        let n = rows.filter { $0.status == s }.count
        if n > 0 { parts.append("\(n) \(word)") }
    }
    if let first = rows.map(\.id.started).min() { parts.append("oldest up " + uptime(now.timeIntervalSince(first)).lowercased()) }
    return (cpus.isEmpty ? nil : cpus.reduce(0, +), rows.reduce(0) { $0 + $1.mem }, parts.joined(separator: " · "))
}

/// "Today 9:12 AM", "Mon 9:12 AM" within a week, else "Oct 6 9:12 AM".
func startedText(_ d: Date, now: Date) -> String {
    let f = DateFormatter()
    f.dateFormat = "h:mm a"
    if Calendar.current.isDate(d, inSameDayAs: now) { return "Today " + f.string(from: d) }
    f.dateFormat = now.timeIntervalSince(d) < 6 * 86400 ? "EEE h:mm a" : "MMM d h:mm a"
    return f.string(from: d)
}

/// Label and value lines of an expanded row.
func detailLines(_ p: Proc, home: String, now: Date) -> [(String, String)] {
    [("Folder", p.folder.map { tilde($0, home: home) } ?? "unknown"),
     ("Binary", tilde(p.binary, home: home)),
     ("Config", p.config.map { tilde($0, home: home) } ?? "default"),
     ("Started by", p.ppid == 1 ? "launchd · orphaned" : "\(p.parent.isEmpty ? "unknown" : p.parent) · PID \(p.ppid)"),
     ("Started", startedText(p.id.started, now: now))]
}

/// CPU times come in Mach ticks, not ns, on Apple silicon.
let timebase: mach_timebase_info_data_t = {
    var t = mach_timebase_info_data_t()
    mach_timebase_info(&t)
    return t
}()

/// The size of the argument area, for KERN_PROCARGS2.
let argMax: Int = {
    var n: Int32 = 0, size = MemoryLayout<Int32>.size, mib = [CTL_KERN, KERN_ARGMAX]
    return sysctl(&mib, 2, &n, &size, nil, 0) == 0 ? Int(n) : 1 << 20
}()

/// This user's pids: the only processes the tray may stop.
func userPids() -> [pid_t] {
    let type = UInt32(PROC_UID_ONLY), uid = UInt32(getuid())
    let bytes = proc_listpids(type, uid, nil, 0)
    guard bytes > 0 else { return [] }
    var pids = [pid_t](repeating: 0, count: Int(bytes) / MemoryLayout<pid_t>.size + 64)   // room for processes started since
    let got = pids.withUnsafeMutableBytes { proc_listpids(type, uid, $0.baseAddress, Int32($0.count)) }
    return pids.prefix(Int(max(got, 0)) / MemoryLayout<pid_t>.size).filter { $0 > 0 }
}

func procName(_ pid: pid_t) -> String? {
    var b = [CChar](repeating: 0, count: 64)   // proc_name fills up to 2 * MAXCOMLEN
    return proc_name(pid, &b, UInt32(b.count)) > 0 ? String(cString: b) : nil
}

/// Parent pid and start time (µs); nil once the process is gone.
func bsdInfo(_ pid: pid_t) -> (ppid: pid_t, start: UInt64)? {
    var i = proc_bsdinfo()
    let size = Int32(MemoryLayout<proc_bsdinfo>.size)
    guard proc_pidinfo(pid, PROC_PIDTBSDINFO, 0, &i, size) == size else { return nil }
    return (pid_t(i.pbi_ppid), i.pbi_start_tvsec * 1_000_000 + i.pbi_start_tvusec)
}

func folder(of pid: pid_t) -> String? {
    var v = proc_vnodepathinfo()
    let size = Int32(MemoryLayout<proc_vnodepathinfo>.size)
    guard proc_pidinfo(pid, PROC_PIDVNODEPATHINFO, 0, &v, size) == size else { return nil }
    var p = v.pvi_cdir.vip_path
    return withUnsafeBytes(of: &p) { String(cString: $0.baseAddress!.assumingMemoryBound(to: CChar.self)) }
}

func path(of pid: pid_t) -> String? {
    var b = [CChar](repeating: 0, count: 4096)   // PROC_PIDPATHINFO_MAXSIZE
    return proc_pidpath(pid, &b, UInt32(b.count)) > 0 ? String(cString: b) : nil
}

func args(of pid: pid_t) -> [String]? {
    var mib = [CTL_KERN, KERN_PROCARGS2, pid], size = argMax
    var b = [UInt8](repeating: 0, count: size)
    guard sysctl(&mib, 3, &b, &size, nil, 0) == 0 else { return nil }
    return parseProcArgs(Array(b.prefix(size)))
}

/// CPU time in ns and memory footprint in bytes, as Activity Monitor counts them; nil once it is gone.
func usage(of pid: pid_t) -> (cpu: UInt64, mem: UInt64)? {
    var ri = rusage_info_v2()
    let rc = withUnsafeMutablePointer(to: &ri) {
        $0.withMemoryRebound(to: rusage_info_t?.self, capacity: 1) { proc_pid_rusage(pid, RUSAGE_INFO_V2, $0) }
    }
    guard rc == 0 else { return nil }
    return ((ri.ri_user_time + ri.ri_system_time) * UInt64(timebase.numer) / UInt64(timebase.denom), ri.ri_phys_footprint)
}

/// Finds and measures the running servers. What never changes for a process (its arguments,
/// binary and folder) is read once, so a tick reads only names, parents and usage.
final class Scanner {
    private struct Fixed { let binary: String; let folder: String?; let config: String? }
    private var fixed: [ServerID: Fixed] = [:]
    private var others: Set<ServerID> = []      // trello-mcp processes that are not servers

    func scan() -> [Proc] {
        var out: [Proc] = [], nextFixed: [ServerID: Fixed] = [:], nextOthers: Set<ServerID> = []
        for pid in userPids() where procName(pid) == serverName {
            // A failing call means the process just exited: skip it.
            guard let b = bsdInfo(pid) else { continue }
            let id = ServerID(pid: pid, start: b.start)
            if others.contains(id) { nextOthers.insert(id); continue }
            var f = fixed[id]
            if f == nil {
                guard let argv = args(of: pid) else { continue }
                guard isServer(argv) else { nextOthers.insert(id); continue }
                f = Fixed(binary: path(of: pid) ?? argv.first ?? serverName, folder: folder(of: pid), config: configArg(argv))
            }
            guard let f, let u = usage(of: pid) else { continue }
            nextFixed[id] = f
            out.append(Proc(id: id, ppid: b.ppid, parent: procName(b.ppid) ?? "", folder: f.folder, binary: f.binary,
                            config: f.config, cpuNs: u.cpu, mem: u.mem))
        }
        fixed = nextFixed
        others = nextOthers
        return out
    }
}

// MARK: - Stop

/// The process still runs under this pid and start time, with this name.
func alive(_ id: ServerID, name: String) -> Bool { procName(id.pid) == name && bsdInfo(id.pid)?.start == id.start }

/// Why kill failed; nil when the process was already gone.
func stopFailure(_ pid: pid_t, _ e: Int32) -> String? {
    e == ESRCH ? nil : "Could not stop PID \(pid): \(String(cString: strerror(e)))"
}

/// Stops `id` if it still runs as `name`: SIGTERM, then SIGKILL after `grace` s if it lives on.
/// done gets nil once it is stopped or gone, else why not: at once when nothing was sent, else on
/// the main queue after the grace period.
func stop(_ id: ServerID, name: String, grace: TimeInterval = 3, done: @escaping (String?) -> Void) {
    guard alive(id, name: name) else { return done(nil) }   // gone, or its pid now belongs to another process
    if kill(id.pid, SIGTERM) != 0 { return done(stopFailure(id.pid, errno)) }
    DispatchQueue.main.asyncAfter(deadline: .now() + grace) {
        if alive(id, name: name) { kill(id.pid, SIGKILL) }
        done(nil)
    }
}

enum W { case r, m, b }

/// Helvetica Neue at a fixed size, with tabular digits.
func hvFont(_ size: CGFloat, _ w: W = .r) -> NSFont {
    let f = NSFont(name: w == .b ? "HelveticaNeue-Bold" : w == .m ? "HelveticaNeue-Medium" : "HelveticaNeue", size: size) ?? .systemFont(ofSize: size)
    let tnum: [NSFontDescriptor.FeatureKey: Int] = [.typeIdentifier: kNumberSpacingType, .selectorIdentifier: kMonospacedNumbersSelector]
    return NSFont(descriptor: f.fontDescriptor.addingAttributes([.featureSettings: [tnum]]), size: size) ?? f
}

/// A text label. `em` is letter-spacing in em; `wrap` is the width it wraps at, else it stays on one line, cut per `cut`.
func label(_ s: String, _ size: CGFloat, _ w: W = .r, em: CGFloat = 0, _ color: NSColor, wrap: CGFloat? = nil,
           align: NSTextAlignment = .left, cut: NSLineBreakMode = .byTruncatingTail) -> NSTextField {
    let ps = NSMutableParagraphStyle()
    ps.alignment = align
    ps.lineBreakMode = wrap == nil ? cut : .byWordWrapping
    let a = NSAttributedString(string: s, attributes: [.font: hvFont(size, w), .kern: em * size, .foregroundColor: color, .paragraphStyle: ps])
    guard let wrap else { return NSTextField(labelWithAttributedString: a) }
    let f = NSTextField(wrappingLabelWithString: "")
    f.isSelectable = false
    f.attributedStringValue = a
    f.preferredMaxLayoutWidth = wrap
    return f
}

/// A regular-weight label.
func label(_ s: String, _ size: CGFloat, _ color: NSColor, wrap: CGFloat? = nil, align: NSTextAlignment = .left) -> NSTextField {
    label(s, size, .r, color, wrap: wrap, align: align)
}

func recolor(_ f: NSTextField, _ c: NSColor) {
    let a = NSMutableAttributedString(attributedString: f.attributedStringValue)
    a.addAttribute(.foregroundColor, value: c, range: NSRange(location: 0, length: a.length))
    f.attributedStringValue = a
}

/// Replaces a label's text and color, keeping its font, kerning and paragraph style; skips a no-op.
/// Labels are never empty, so the first character's attributes carry over.
func setText(_ f: NSTextField, _ s: String, _ c: NSColor) {
    let old = f.attributedStringValue
    guard old.length > 0, old.string != s || old.attribute(.foregroundColor, at: 0, effectiveRange: nil) as? NSColor != c else { return }
    let a = NSMutableAttributedString(attributedString: old)
    a.replaceCharacters(in: NSRange(location: 0, length: a.length), with: s)
    a.addAttribute(.foregroundColor, value: c, range: NSRange(location: 0, length: a.length))
    f.attributedStringValue = a
}

/// Flipped, so a scroll view shows it from the top.
final class Stack: NSStackView {
    override var isFlipped: Bool { true }
}

/// A column; each item stretches to its width less the insets.
func vstack(_ items: [NSView], _ spacing: CGFloat = 0, inset: NSEdgeInsets = NSEdgeInsetsZero) -> Stack {
    let s = Stack(views: items)
    s.orientation = .vertical
    s.alignment = .leading
    s.spacing = spacing
    s.edgeInsets = inset
    for v in items { v.widthAnchor.constraint(equalTo: s.widthAnchor, constant: -inset.left - inset.right).isActive = true }
    return s
}

/// A row, centered or top-aligned; a `spacer()` or a `stretch`ed item takes the room left.
func hstack(_ items: [NSView], _ spacing: CGFloat = 0, top: Bool = false) -> Stack {
    let s = Stack(views: items)
    s.orientation = .horizontal
    s.alignment = top ? .top : .centerY
    s.distribution = .fill
    s.spacing = spacing
    return s
}

@discardableResult
func stretch<V: NSView>(_ v: V) -> V {
    v.setContentHuggingPriority(.init(1), for: .horizontal)
    return v
}

func spacer() -> NSView { stretch(NSView()) }

@discardableResult
func fixed<V: NSView>(_ v: V, w: CGFloat? = nil, h: CGFloat? = nil) -> V {
    v.translatesAutoresizingMaskIntoConstraints = false
    if let w { v.widthAnchor.constraint(equalToConstant: w).isActive = true }
    if let h { v.heightAnchor.constraint(equalToConstant: h).isActive = true }
    return v
}

/// A plain block of color: rules, squares.
func block(_ c: NSColor, w: CGFloat? = nil, h: CGFloat? = nil) -> NSView {
    let v = NSView()
    v.wantsLayer = true
    v.layer?.backgroundColor = c.cgColor
    return fixed(v, w: w, h: h)
}

/// `v` inside `inset`.
func pad(_ v: NSView, _ inset: NSEdgeInsets) -> Stack { vstack([v], inset: inset) }

func edges(_ t: CGFloat, _ l: CGFloat, _ b: CGFloat, _ r: CGFloat) -> NSEdgeInsets { NSEdgeInsets(top: t, left: l, bottom: b, right: r) }

/// Sets a layer property without Core Animation's implicit fade.
func still(_ f: () -> Void) {
    CATransaction.begin()
    CATransaction.setDisableActions(true)
    f()
    CATransaction.commit()
}

/// The board mark: three columns of different heights hanging from the top, like lists on a board.
let boardColumns: [CGFloat] = [1, 0.65, 0.8]

func boardMark(_ h: CGFloat, _ c: NSColor) -> NSView {
    hstack(boardColumns.map { block(c, w: h / 4, h: h * $0) }, h / 8, top: true)
}

/// A 3/4 ring turning every 0.7 s, unless Reduce Motion: the busy spinner.
func spinner(_ size: CGFloat, _ c: NSColor) -> NSView {
    let v = fixed(NSView(frame: NSRect(x: 0, y: 0, width: size, height: size)), w: size, h: size)
    v.wantsLayer = true
    let l = CAShapeLayer()
    l.frame = v.bounds
    l.path = CGPath(ellipseIn: v.bounds.insetBy(dx: 1, dy: 1), transform: nil)
    l.fillColor = nil
    l.strokeColor = c.cgColor
    l.lineWidth = 2
    l.strokeEnd = 0.75
    l.contentsScale = NSScreen.main?.backingScaleFactor ?? 2
    v.layer?.addSublayer(l)
    if !NSWorkspace.shared.accessibilityDisplayShouldReduceMotion {
        let a = CABasicAnimation(keyPath: "transform.rotation.z")
        a.byValue = -2 * Double.pi      // y-up layers: negative turns clockwise
        a.duration = 0.7
        a.repeatCount = .infinity
        l.add(a, forKey: "turn")
    }
    return v
}

/// A borderless button made of its own views; `paint` restyles it when it turns hot (hover or press) or back.
/// The focus ring is the system's.
final class Press: NSButton {
    var paint: ((Press, Bool) -> Void)? { didSet { repaint() } }
    override var isEnabled: Bool { didSet { repaint() } }
    private let content: NSView, pad: (CGFloat, CGFloat), minHeight: CGFloat, act: () -> Void
    private var hover = false, down = false
    private lazy var fit = content.fittingSize

    /// `pad` is (leading, trailing). `fill` stretches `content` across; otherwise it sits in the middle.
    init(_ content: NSView, pad: (CGFloat, CGFloat) = (0, 0), minHeight: CGFloat = 0, fill: Bool = false, _ act: @escaping () -> Void) {
        self.content = content
        self.pad = pad
        self.minHeight = minHeight
        self.act = act
        super.init(frame: .zero)
        title = ""
        isBordered = false
        wantsLayer = true
        target = self
        action = #selector(fire)
        translatesAutoresizingMaskIntoConstraints = false
        content.translatesAutoresizingMaskIntoConstraints = false
        addSubview(content)
        NSLayoutConstraint.activate([
            content.centerYAnchor.constraint(equalTo: centerYAnchor),
            content.topAnchor.constraint(greaterThanOrEqualTo: topAnchor),
        ] + (fill ? [
            content.leadingAnchor.constraint(equalTo: leadingAnchor, constant: pad.0),
            content.trailingAnchor.constraint(equalTo: trailingAnchor, constant: -pad.1),
        ] : [
            content.centerXAnchor.constraint(equalTo: centerXAnchor, constant: (pad.0 - pad.1) / 2),
            content.leadingAnchor.constraint(greaterThanOrEqualTo: leadingAnchor, constant: pad.0),
        ]))
        addTrackingArea(NSTrackingArea(rect: .zero, options: [.mouseEnteredAndExited, .activeAlways, .inVisibleRect], owner: self))
    }

    required init?(coder: NSCoder) { fatalError() }

    override var intrinsicContentSize: NSSize { NSSize(width: fit.width + pad.0 + pad.1, height: max(minHeight, fit.height)) }
    override var focusRingMaskBounds: NSRect { bounds }
    override func drawFocusRingMask() { bounds.fill() }
    override func accessibilityChildren() -> [Any]? { nil }
    override func mouseEntered(with e: NSEvent) { hover = true; repaint() }
    override func mouseExited(with e: NSEvent) { hover = false; repaint() }

    override func mouseDown(with e: NSEvent) {
        down = true
        repaint()
        super.mouseDown(with: e)    // tracks until the mouse is up and fires the action
        down = false
        repaint()
    }

    @objc private func fire() { act() }
    private func repaint() { paint?(self, isEnabled && (hover || down)) }
}

enum BtnKind { case outline, red }

/// A boxed button (the design's .btn): 2 pt border, ink fill while hot; 40% when disabled.
func btn(_ kind: BtnKind, _ p: Pal, _ title: String, size: CGFloat = 13, h: CGFloat = 36, pad: CGFloat = 14,
         enabled: Bool = true, _ act: @escaping () -> Void) -> Press {
    let l = label(title, size, .b, p.ink)
    let b = Press(l, pad: (pad, pad), minHeight: h, act)
    b.layer?.borderWidth = 2
    b.isEnabled = enabled
    b.alphaValue = enabled ? 1 : 0.4
    b.paint = { b, hot in
        let (bg, fg, bd): (NSColor, NSColor, NSColor) = switch (kind, hot) {
        case (.outline, false): (.clear, p.ink, p.ink)
        case (.red, false): (swissRed, .white, swissRed)
        default: (p.ink, p.paper, p.ink)
        }
        b.layer?.backgroundColor = bg.cgColor
        b.layer?.borderColor = bd.cgColor
        recolor(l, fg)
    }
    b.setAccessibilityLabel(title)
    return b
}

/// A text-only button (the design's .txt): red ink while hot.
func txtBtn(_ p: Pal, _ title: String, _ w: W, color: NSColor? = nil, pad: (CGFloat, CGFloat), key: String = "", _ act: @escaping () -> Void) -> Press {
    let l = label(title, 13, w, color ?? p.ink)
    let b = Press(l, pad: pad, minHeight: 36, act)
    b.paint = { _, hot in recolor(l, hot ? p.redInk : color ?? p.ink) }
    b.keyEquivalent = key
    b.keyEquivalentModifierMask = .command
    b.setAccessibilityLabel(title)
    return b
}

/// The panel's content: rebuilt from the model on each change of shape while it shows.
final class PanelController: NSViewController {
    let m: PanelModel
    private var queued = false
    // What a tick updates in place; filled by render().
    private struct RowRefs { let head: Press; let cpu, mem, status: NSTextField; let square: NSView? }
    private var rowRefs: [ServerID: RowRefs] = [:]
    private var figRefs: [NSTextField] = []     // servers, CPU, memory
    private var noteRef: NSTextField?
    private var statsRef: NSTextField?
    private var p = pal(dark: false, inverted: false), inv = pal(dark: false, inverted: true)

    init(_ m: PanelModel) {
        self.m = m
        super.init(nibName: nil, bundle: nil)
        m.changed = { [unowned self] in
            guard !queued else { return }
            queued = true
            DispatchQueue.main.async { [unowned self] in
                if queued, view.window?.isVisible == true { render() }
                queued = false
            }
        }
        m.ticked = { [unowned self] in if !queued { tick() } }    // a queued render covers the tick
    }

    required init?(coder: NSCoder) { fatalError() }

    override func loadView() {
        let r = Root()
        r.wantsLayer = true
        r.onAppearance = { [unowned self] in render() }
        view = r
    }

    func render() {
        queued = false      // this render covers changes still queued
        let dark = view.effectiveAppearance.bestMatch(from: [.darkAqua, .aqua]) == .darkAqua
        p = pal(dark: dark, inverted: false)
        inv = pal(dark: dark, inverted: true)
        rowRefs = [:]
        figRefs = []
        noteRef = nil
        // Header and footer stay put; the middle scrolls once it outgrows the screen.
        let mid = vstack(middle(), 16)
        mid.widthAnchor.constraint(equalToConstant: 328).isActive = true
        let h = mid.fittingSize.height
        let scroll = NSScrollView()
        scroll.drawsBackground = false
        scroll.hasVerticalScroller = h > m.cap
        scroll.verticalScrollElasticity = h > m.cap ? .automatic : .none
        scroll.documentView = mid
        NSLayoutConstraint.activate([
            mid.topAnchor.constraint(equalTo: scroll.contentView.topAnchor),
            mid.leadingAnchor.constraint(equalTo: scroll.contentView.leadingAnchor),
            scroll.heightAnchor.constraint(equalToConstant: min(h, m.cap)),
        ])
        let col = vstack([header(), scroll, footer()], 16, inset: edges(16, 16, 16, 16))
        col.translatesAutoresizingMaskIntoConstraints = false
        view.subviews.forEach { $0.removeFromSuperview() }
        view.addSubview(col)
        NSLayoutConstraint.activate([
            col.widthAnchor.constraint(equalToConstant: 360),
            col.topAnchor.constraint(equalTo: view.topAnchor),
            col.leadingAnchor.constraint(equalTo: view.leadingAnchor),
        ])
        view.layer?.backgroundColor = p.paper.cgColor
        let size = col.fittingSize
        if let w = view.window {    // keep the top edge, under the status item
            w.setFrame(NSRect(x: w.frame.minX, y: w.frame.maxY - size.height, width: size.width, height: size.height), display: true)
        }
    }

    /// New numbers for the same rows: text, colors and VoiceOver labels in place.
    func tick() {
        guard view.window?.isVisible == true else { return }
        let now = Date()
        for r in m.rows {
            guard let x = rowRefs[r.id] else { continue }
            setText(x.cpu, cpuText(r.cpu), p.fig(r.cpu))
            setText(x.mem, memText(r.mem), p.ink)
            let c = p.status(r.status)
            setText(x.status, statusLine(r, now: now), c)
            if let sq = x.square { still { sq.layer?.backgroundColor = c.cgColor } }
            x.head.setAccessibilityLabel(rowSummary(r, now: now))
        }
        let t = totals(m.rows, now: now)
        if figRefs.count == 3 {
            setText(figRefs[1], cpuText(t.cpu), inv.ink)
            setText(figRefs[2], memText(t.mem), inv.ink)
        }
        if let n = noteRef { setText(n, t.note, inv.muted) }
        if let s = statsRef, !m.stats.isEmpty { setText(s, m.stats, p.muted) }
    }

    func middle() -> [NSView] {
        var out: [NSView] = []
        if let e = m.error {
            let box = pad(label(e, 13, .b, p.redInk, wrap: 308), edges(10, 10, 10, 10))
            box.wantsLayer = true
            box.layer?.borderWidth = 2
            box.layer?.borderColor = p.redInk.cgColor
            out.append(box)
        }
        return out + (m.rows.isEmpty ? [empty()] : [totalsBlock(), table()])

    func header() -> NSView {

                          label("live · every 2 s", 12, p.muted)], 12)
        return vstack([top, block(p.ink, h: 4)], 12)

            txtBtn(p, "Open Log", .b, pad: (0, 8), key: "l") { [unowned self] in m.onLog() },
            spacer(),
            txtBtn(p, "Quit", .r, color: p.muted, pad: (8, 0), key: "q") { [unowned self] in m.onQuit() },

        let s = label(m.stats.isEmpty ? "Tray: —" : m.stats, 12, p.muted)

            recolor(name, hot ? red : ink)

        }

        head.setAccessibilityValue(open ? "expanded" : "collapsed")

    }

    func details(_ r: Row) -> NSView {
        let lines: [NSView] = detailLines(r.proc, home: userHome, now: Date()).map { k, v in

    }

    func empty() -> NSView {
        let text = fixed(vstack([
            label("No servers running", 17, .b, p.ink, wrap: 230),
            label("Claude Code and Codex start one trello-mcp per session. Open a project that uses it and it shows here.", 13, p.muted, wrap: 230),
        ], 8), w: 230)

    }

    var timer: Timer?           // the next sample, only while the panel shows
    var last: [ServerID: (cpu: UInt64, at: TimeInterval)] = [:]    // each server's previous sample
    var mine: (cpu: UInt64, at: TimeInterval)?                      // the tray's own previous sample
    var stopping: Set<ServerID> = []

    func applicationDidFinishLaunching(_ n: Notification) {
        item = NSStatusBar.system.statusItem(withLength: NSStatusItem.variableLength)
        item.button?.image = boardImage()
        item.button?.toolTip = "Trello MCP"
        item.button?.setAccessibilityLabel("Trello MCP")
        item.button?.target = self
        item.button?.action = #selector(togglePanel)
        model.onStop = { [unowned self] in stopServer($0) }
        model.onLog = { [unowned self] in closePanel(); NSWorkspace.shared.open(logURL) }
        model.onQuit = { exit(0) }      // exit 0: the LaunchAgent leaves it down until the next login
        window.contentViewController = panel
        window.level = .popUpMenu
        window.hasShadow = true
        window.hidesOnDeactivate = false
        window.isReleasedWhenClosed = false
        window.onClose = { [unowned self] in closePanel() }
    }

    @objc func togglePanel() { if window.isVisible { closePanel() } else { openPanel() } }

    func openPanel() {
        guard let b = item.button, let bar = b.window else { return }
        let r = bar.convertToScreen(b.convert(b.bounds, to: nil)), vis = (bar.screen ?? NSScreen.main)?.visibleFrame ?? .zero
        model.cap = vis.height - 160    // room for header and footer
        last = [:]                      // CPU since the panel last closed would be a stale average
        mine = nil
        sample()
        panel.render()                  // sizes the window
        let s = window.frame.size
        window.setFrameOrigin(NSPoint(x: min(max(r.midX - s.width / 2, vis.minX), vis.maxX - s.width), y: bar.frame.minY - s.height))
        window.makeKeyAndOrderFront(nil)
        // The status item's own clicks reach us as global events; its action does the toggling.
        clicks = NSEvent.addGlobalMonitorForEvents(matching: [.leftMouseDown, .rightMouseDown]) { [unowned self] e in
            if !r.contains(e.locationInWindow) { closePanel() }
        }
        sampleAgain(after: 0.5)         // CPU needs a second sample: show it almost at once
    }

    /// Samples after `delay`, then every 2 s while the panel shows. The tolerance lets macOS batch wakeups.
    func sampleAgain(after delay: TimeInterval) {
        let t = Timer(timeInterval: delay, repeats: false) { [unowned self] _ in
            sample()
            sampleAgain(after: 2)
        }
        t.tolerance = 0.2
        RunLoop.main.add(t, forMode: .common)
        timer = t
    }

    func closePanel() {
        guard window.isVisible else { return }
        window.orderOut(nil)
        if let c = clicks { NSEvent.removeMonitor(c) }
        clicks = nil
        timer?.invalidate()
        timer = nil
        model.error = nil
        model.open = nil
    }

    /// Reads the servers and the tray's own usage and hands them to the panel.
    func sample() {
        let at = ProcessInfo.processInfo.systemUptime
        let procs = scanner.scan()
        var cpu: [ServerID: Double] = [:], next: [ServerID: (cpu: UInt64, at: TimeInterval)] = [:]
        for p in procs {
            next[p.id] = (p.cpuNs, at)
            cpu[p.id] = cpuPercent(last[p.id], (p.cpuNs, at))
        }
        last = next
        stopping.formIntersection(next.keys)    // a stopped server that is gone is done stopping
        model.rows = rows(procs, cpu: cpu, stopping: stopping, home: userHome)
        if let u = usage(of: getpid()) {
            model.stats = trayStats(cpu: cpuPercent(mine, (u.cpu, at)), mem: u.mem)
            mine = (u.cpu, at)
        }
    }

    func stopServer(_ r: Row) {
        guard !stopping.contains(r.id) else { return }
        stopping.insert(r.id)
        model.error = nil
        sample()
        NSLog("stopping trello-mcp PID \(r.id.pid) (\(r.label))")
        stop(r.id, name: serverName) { [unowned self] fail in
            if let fail {
                stopping.remove(r.id)
                NSLog(fail)
                show(error: fail)
            }
            if window.isVisible { sample() }
        }
    }

    /// Shows a failure in the panel; reopens it if a click elsewhere already closed it, so it is seen once.
    func show(error: String) {
        if !window.isVisible { openPanel() }
        model.error = error
        NSAccessibility.post(element: NSApp as Any, notification: .announcementRequested,
                             userInfo: [.announcement: error, .priority: NSAccessibilityPriorityLevel.high.rawValue])
    }
}

let app = NSApplication.shared
let tray = Tray()
app.delegate = tray
app.setActivationPolicy(.accessory)
app.run()
```

## Menu bar app (macOS)

Trello MCP is a menu bar app that lists every running trello-mcp server: the project folder its
